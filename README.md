# 💊 Türkiye Nöbetçi Eczaneler

Türkiye genelinde nöbetçi eczaneleri anlık olarak gösteren web uygulaması.

## 🎯 Özellikler

- 🔍 İl veya ilçe adı ile arama
- 📱 Mobil uyumlu tasarım
- ⚡ Anlık veri çekme
- 🗺️ Harita ve telefon bağlantıları
- 🚀 Vercel ile otomatik deploy

## 🛠️ Kurulum

```bash
# Gereksinimleri yükle
pip install -r requirements.txt

# Uygulamayı başlat
python eczane.py
